## 3. 排版与反模板禁令
- 标题与大百分比数字使用衬线体：`"Noto Serif SC", "Source Han Serif SC", "Songti SC", Georgia, serif`；
- 参数、编号、概率、日志使用等宽体：`"JetBrains Mono", ui-monospace, Menlo, Consolas, monospace` + `font-variant-numeric: tabular-nums`；
- **边界鲜明**：大区之间必须使用 `1.5px solid var(--rule-strong)` 分割；顶部上下文栏使用双线底边（`1.5px` 实线 + `3px` 留白 + `1px` 细线）；科学图版外框四角带 `8×8px` 精密墨色角标；
- **严格清理旧版硬伤**：
  1. 彻底删除 Logo 旁 `M2` 徽章；
  2. 彻底删除界面中的 `howToCheck` 英文变量名，统一改为 `查看排查核查方法`；
  3. 彻底移除 `min-width: 1180px` 硬编码；
  4. 右侧底部预留 `pb-16`（64px）安全区，绝对避免被右下角 `Made with Qoder` 悬浮标遮挡；
  5. 禁止使用厚重圆角 SaaS 投影卡片，保持锐利学术刊物方角（`0–2px`）。

## 4. 整体空间架构（仿桌面 QQ 左侧目录树 + 右侧主工作区）
- **左侧固定目录栏（桌面宽 `258px`，`<1024px` 顶部折叠为抽屉菜单）**：
  1. 品牌头：`LabChronos` + `纸 ／ 光` 切换按钮；
  2. 快捷搜索框（支持搜编号、病例名、学科、真因）+ **跨学科通用状态筛选条**：`全部 / 进行中 / 我的 / 已归档`（严禁写死固定学科按钮）；
  3. 竖向目录树（选中项左侧 `3px solid var(--seal)` 竖条高亮）：
     - `当前病例`（红点 + 当前病例短标题 + 实时最高概率/已锁定徽章）；
     - `+ 新建病例`（点击后右侧主工作区直接切换为整页新建诊断表单，不做小弹窗）；
     - `往期病例`（仿桌面 QQ 分组：点击向下平滑展开/收起，列出全部内置病例、新建病例与已存档记录，每项含状态圆点、短标题、一句话摘要、编号与领域，点击任意项右侧即时切换）；
     - `翻车博物馆`（公共避坑库视图入口）；
  4. 下半区功能模块（消除左侧大片留白）：
     - 「取证流程追踪」卡片（实时同步 5 步：`01 客观取证 → 02 贝叶斯先验 → 03 鉴别追问 → 04 实时剪枝 → 05 单变量处方`）；
     - `2×2` 实验室指标小卡（病例总数 / 评测 Top-1 86.7% / 平均 2 步收敛 / 单变量原则）+ 快捷键与边界声明提示。

- **右侧主工作区（随左侧点击即时切换 3 种视图）**：
  - **视图 A · 当前病例（双栏 50% / 50%）**：
    - 左栏 `I · 实验取证`：副标题 +（自定义病例显式展示科学边界声明条）+ 3 个核心指标盒 + 大幅 `图版 I`（支持点击放大 Lightbox，保留 `bbox` 叠加框；无图自定义病例自动将 `KEY=VALUE` 日志渲染为双列条件表）+ 三标签区（`观测症状 / 原始日志 / 条件表`，日志必须自动换行无横滚条）；
    - 右栏上 `II · 因果墨环与假设分布`：左侧紧凑 **`204×204px` Canvas 水墨环**（不喧宾夺主，中央显示大字号百分比，锁定后左下盖朱砂「真因」印）+ 右侧**按概率降序排列的结构化假设账本**（进度条 + 子原因 + `<15%` 虚线删除线剪枝态）；
    - 右栏下 `III · 鉴别追问 / 最小对照处方`：每次聚焦 1 道题（支持键盘 `1/2/3` 作答、`R` 重置，带折叠核查方法与“直接锁定”）；锁定后切换为单变量参数 Diff（旧值朱红删除线 → 新值翠绿加粗）+ 修复前后预期曲线对比图 + `导出复盘卡` / `存入往期病例` / `重新追问`。
  - **视图 B · 新建病例（整页工作区）**：
    - `01 实验日志`（带自动识别 `KEY=VALUE` 计数提示）+ `02 失败图版（可选，支持拖拽预览）` + `03 学科领域`（`自动识别 / AI·ML / 生化 / 物理电子 / 通用·其他`）+ `开始取证 →`；提交后在主区展示 3 阶段实时进度条，完成后切入视图 A 并自动写入左侧「往期病例」。
  - **视图 C · 翻车博物馆 / 归档复盘视图**：展示归档记录与公共避坑库，支持一键切回交互实操。
